# JSON 格式化与校验工具

处理接口响应、配置文件或日志中的 JSON 时，可以使用 JavaScript中文网的在线 JSON 工具快速完成格式化、压缩和校验。

## 在线使用

<https://www.javascriptc.com/tools/json-formatter/>

## 支持的操作

- 格式化 JSON，选择 2 个空格、4 个空格或 Tab 缩进；
- 压缩 JSON；
- 校验语法并查看错误信息；
- 复制结果或下载为 `.json` 文件；
- 在浏览器本地处理输入内容。

## 适用场景

- 阅读 API 返回结果；
- 检查配置文件语法；
- 整理日志中的 JSON 片段；
- 提交接口调试数据前清理格式。

## 隐私提示

输入内容在浏览器中处理，不会上传到 JavaScript中文网。不要把生产环境密钥、个人数据或完整数据库记录粘贴到任何在线工具中。

更多工具：<https://www.javascriptc.com/tools/>
