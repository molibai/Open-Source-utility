# JavaScript Regex Tester

JavaScript中文网的正则表达式测试工具适合快速检查匹配结果、捕获组和替换预览。

## 在线使用

<https://www.javascriptc.com/tools/regex-tester/>

## 使用方式

1. 输入正则表达式；
2. 设置 JavaScript flags，例如 `g`、`i` 或 `m`；
3. 粘贴测试文本；
4. 查看匹配位置、捕获组和替换结果；
5. 复制完整的正则表达式。

工具内置邮箱、URL、手机号、日期、IPv4、颜色值、空白字符和 HTML 标签片段示例，便于从常见问题开始修改。

## 运行方式与限制

表达式在浏览器隔离 Worker 中运行，测试文本、表达式和替换内容不会上传。工具设置了长度、匹配数量和执行时间限制，以避免复杂表达式长时间占用浏览器。

正则表达式不能替代完整的 HTML 解析器，也不能仅凭格式判断邮箱或手机号真实有效。
