# Markdown 转 HTML 工具

JavaScript中文网的 Markdown 转 HTML 工具适合把 README 草稿、文档片段或博客内容转换成 HTML，并立即查看预览。

## 在线使用

<https://www.javascriptc.com/tools/markdown-to-html/>

## 支持内容

- 标题、段落和引用；
- 有序列表和无序列表；
- 粗体、斜体、删除线和行内代码；
- fenced code block；
- 基础表格；
- HTML 结果复制和下载。

## 隐私和预览安全

转换在浏览器本地完成，原始输入不会上传。预览使用 sandbox iframe，原始 HTML 会先转义。输出发布到生产站点前，仍应检查链接、代码和 HTML 结构。

在线工具：<https://www.javascriptc.com/tools/markdown-to-html/>
